# Ego WM 盲审工作台

团队使用这个页面比较一段人类示范和对应的机器人回放，独立判定任务是否完成、接触方式是否符合、动作过程是否一致。

[打开工作台](https://unimotionrec.github.io/ego-wm-eval-review/)

## 审阅

1. 导入组织者发来的 ZIP。也可以选择解压后的文件夹。首页有两个合成练习案例。
2. 输入分配给你的审阅编号。用同步播放和速度按钮查看视频，填写三个判断。能判断时写依据和回放时间。证据缺失时选「无法判断」并说明原因。
3. 点击「完成并下一条」。完成后导出 JSONL，交回组织者。草稿保存在当前浏览器。刷新后重新导入同一批次可继续。

## 接入评估流水线

导出盲审素材后，用 [打包工具](scripts/README.md) 生成可导入的 ZIP。素材只带随机案例编号、任务说明、视频和时间证据。组织者单独保管案例编号映射，两名审阅者分别完成后再合并导出的 JSONL。遇到分歧，可发同一素材给第三名审阅者，并把其批次清单的 `assignment_role` 设为 `arbiter`。

页面与合成练习公开部署。组内真实视频和标注文件通过组内渠道交接，导入和导出时由浏览器本地处理。

## 本地开发

用 `python3 -m http.server 8794 --directory docs` 启动，在浏览器打开 `http://localhost:8794`。页面无需构建步骤。GitHub Pages 的发布源为 `main:/docs`。
