# Ego WM 盲审工作台

[打开工作台](https://unimotionrec.github.io/ego-wm-eval-review/)

首页载入六条开发样例。选择分配给你的编号，对照人类示范和机器人回放，独立判断任务目标、接触策略和运动过程。每条任务卡列出本次需要核对的阶段和要求。

- 全部要求成立时，点一次「已完成」或「符合」。
- 明确偏离或证据不足时，点对应原因。系统保存观察窗口或当前已解码帧。也可以追加证据。
- 遇到错片、时间错配或判据冲突，提交材料问题。草稿保存在当前浏览器，整批完成后导出一个文件。

机器人回放可切换总览和手物近景。物理面板按同一执行中的求解器步展示原始接触，逐帧对应与媒体播放时间分别显示。

## 可用性试验

[打开试验入口](https://unimotionrec.github.io/ego-wm-eval-review/a1.html)。两位审阅者按各自编号进入，页面按预登记顺序切换旧版与新版，完成后每人导出一份试验记录。操作统计只随本地导出文件保存。首页的开发样例和可用性试验采用不同编号。

## 评估接口

审阅包和每条导出记录绑定源视频、执行、任务卡、映射和评审范围。第三名审阅者只处理结论分歧的判断项。打包与裁决命令见 [审阅包工具](scripts/README.md)。

本地运行 python3 -m http.server 8794 --directory docs，然后打开 http://localhost:8794。GitHub Pages 从 main:/docs 发布。
